Локальный сервер генерации QR-кодов.

Работает в локальной сети, имеет UDP и TCP сокет на одном порту (пока что 8888).
Приняв байтовое сообщение b"Who's QRcode server?" на UDP сокет, отвечает на него b"I am the QRcode server." непосредственно на адрес спросившего.
Клиент (VBA Excel макрос) отправляет UDP-broadcast сообщение, получает ответ серера и извлекает адрес отправителя.
Клиент подключается на TCP по тому же адресу и порту, отправляет строку типа "текст1\nтекст2\nтекст3\n...\nтекстi\n\n".
Сервер разделяет строку и создает задачи по генерации PNG файлов (cpu-bound), используя пул потоков (freethreaded, no GIL).
PNG файлы теми же потоками записываются байтами, кодируются в base64.
Сервер собирает все файлы, сшивает их через батовый b'\n', с b'\n\n' в конце.
Собранную строку сервер отправляет назад и закрывает соединение.
Клиент разделяет строку, декодирует base64, сохраняет png файлы и вставляет их на лист Excel.

Активно использую с коллегами на складе с адресным хранением, позволяет через простые модификации листа Excel печатать любые этикетки.
Был создан на замену API сторонних сервисов.
